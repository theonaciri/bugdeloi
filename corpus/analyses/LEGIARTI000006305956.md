# Article 1378 bis du code général des impôts

Source [LEGI LEGIARTI000006305956](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006305956), version du 1979-07-01.

Empreinte normalisée SHA-256 `d7c4cd8f7470a0dac33287d40c0e0673af378117027d8714fa1acddd42572bc9`.

> Les mutations de toute nature ayant pour objet, en matière de bail emphytéotique, soit le droit du bailleur, soit le droit du preneur, sont soumises aux dispositions du présent code concernant les transmissions de propriétés d'immeubles.

## Interface proposée

`AssimilationMutationsBailEmphytéotique1378Bis@v1`

### Entrées

- `appréciation_mutation_en_matière_de_bail_emphytéotique` (booléen).
- `objet` (énumération (droit du bailleur, droit du preneur, autre)).

### Sorties

- `renvoi_régime_transmissions_propriété_immeubles` (booléen).

## Classement des alinéas

Calculable lorsque la mutation concerne l’un des deux droits énumérés dans un bail qualifié. Le mode de mutation est indifférent pour ce renvoi. La qualification du bail et la liquidation immobilière restent externes.
